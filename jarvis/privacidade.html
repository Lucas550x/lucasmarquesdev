J.A.R.V.I.S.

Política de Privacidade

Última atualização: 29 de setembro de 2026

O Jarvis é um assistente pessoal de voz para computador, desenvolvido e usado exclusivamente por seu próprio criador. Ele não é distribuído ao público nem oferecido como serviço a terceiros. Esta página explica quais dados o Jarvis acessa e como eles são tratados.

Dados do Google que o Jarvis acessa

Com a autorização explícita do titular da conta, o Jarvis acessa o Google Agenda (escopo calendar) para:

  • ler os compromissos e mostrá-los ou falá-los quando o usuário pergunta pela agenda;
  • exibir o próximo compromisso na tela do assistente;
  • criar eventos e lembretes quando o usuário pede.

O Jarvis não apaga eventos, não acessa outros serviços do Google sem nova autorização e não usa os dados para qualquer finalidade além dessas funções.

Onde os dados ficam

  • As autorizações de acesso (tokens) ficam salvas somente no computador do usuário.
  • O Jarvis não tem servidor próprio e não mantém cópias da agenda em nenhum banco de dados externo.
  • Para responder às perguntas, o texto da conversa e os dados necessários (por exemplo, títulos e horários dos compromissos consultados) são enviados ao modelo de inteligência artificial configurado pelo usuário (atualmente, a API Gemini do Google), apenas para gerar a resposta.

Compartilhamento

Os dados não são vendidos, alugados nem compartilhados com terceiros, nem usados para publicidade.

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google pelo Jarvis obedecerão à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions. Também é possível apagar os arquivos de autorização na pasta data/google do Jarvis.
